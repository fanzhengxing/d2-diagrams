# HTML 包装模板（由 architecture-diagram 的 Cocoon-AI 样式启发） 当用户输出架构图的 SVG 后，可以将其包装进一个暗色主题的 HTML 页面， 包含 Summary Cards、脉冲动画、网格背景。以下是模板结构。 ## 使用方法 ```bash # 1. 生成 SVG d2 --theme=200 arch.d2 arch.svg # 2. 创建 HTML 容器，将 SVG 内嵌 ``` ## HTML 模板结构 ```html [架构图标题]

[架构图标题]

[SVG_CONTENT]

[卡片1标题]

  • • [项目1]
  • • [项目2]
  • • [项目3]

[卡片2标题]

  • • [项目1]
  • • [项目2]
  • • [项目3]

[卡片3标题]

  • • [项目1]
  • • [项目2]
  • • [项目3]
Generated by D2 · [项目名称] · [日期]
```
